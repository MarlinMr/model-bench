About this comparison

Different AI models were given the same prompt: create a living, painterly landscape in a single HTML file. This blind comparison lets you judge the results on their appearance and behavior before knowing who made them.

  • Start with Random page. Watch the scene paint itself, then spend a little time with the finished animation. Try any controls included in the simulation.
  • Compare the experience. Look at composition, painterly detail, natural movement, the startup painting sequence, and how closely the result follows the prompt.
  • Try another result. The viewer's Random page button opens another simulation, avoiding an immediate repeat when more than one is available.
  • Keep it blind. Model names and original filenames are hidden behind anonymous URLs. The banner shows only file size and line count; these describe the output, not its quality.
  • Reveal when ready. Click Reveal model in the viewer's banner to see who made the current simulation. Choosing another page hides the identity again.

The prompt used

I want a web page that is self-contained inside a single HTML file. The entire purpose of the page is to display an animated simulation.

The simulation features a picture frame containing a landscape in the signature painterly style of Bob Ross. Instead of a static image, it is a dynamic, living scene: gentle wind rustles trees, birds fly across the sky, water flows in a stream, clouds drift, and other subtle elements move naturally. The focus should be on art, beauty, and atmosphere rather than strict physical accuracy.

Additionally, elements within the frame should be painted sequentially upon startup—revealing background, mountains, trees, and foreground details one by one as if the artwork is being created live on canvas.

Construct the complete, self-contained HTML file based on these instructions.
